# siftbeam

Sift timestamps and beam durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/siftbeam/

## Install / run

```bash
git clone https://github.com/theworker02/siftbeam.git
cd siftbeam
node src/cli.js
node --test
```
